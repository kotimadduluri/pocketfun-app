# pocketfun-app

Website and privacy policy for Pocket Fun, served by GitHub Pages at
https://kotimadduluri.github.io/pocketfun-app/.

Static HTML and CSS only: `index.html`, `privacy.html`, `404.html`, `style.css`. No build step,
no scripts, no trackers. `.nojekyll` makes Pages serve the files as they are.

No `app-ads.txt` here: AdMob reads it from the root of the developer website's domain, and a
project site lives at `/pocketfun-app/`, not at the root of `kotimadduluri.github.io`. It needs a
user site (`kotimadduluri.github.io` repo) or a custom domain.

Report problems or ask questions in [issues](https://github.com/kotimadduluri/pocketfun-app/issues).
